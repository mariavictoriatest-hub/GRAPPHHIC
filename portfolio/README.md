# Portfolio interactivo · María Victoria

Presentación HTML para enviar a clientes o postular a puestos remotos
(Marketing Manager, Social Media Manager, Paid Media).

Abrí `index.html` en el navegador. Para moverte usá las flechas del teclado, los botones de abajo o deslizá en el celular.

## Cómo editar

Todo el contenido está al principio del `<script>` de `index.html`:

| Bloque | Qué contiene |
|---|---|
| `MARCA` | nombre, bio, email, redes, datos rápidos |
| `PERFILES` | versiones por cliente o puesto |
| `SERVICIOS` | los 3 roles y sus tareas |
| `METRICAS` | contadores animados |
| `CASOS` | casos de éxito con gráfico antes/después |
| `PROCESO`, `HERRAMIENTAS`, `TESTIMONIOS`, `MODALIDADES` | resto de las diapositivas |

**Los datos de métricas, casos, testimonios, precios y el email son ficticios.** Reemplazalos por los reales.

## Una versión por cliente

Agregá una entrada en `PERFILES` y abrí el archivo con `#clave` al final:

- `index.html#cafe-nativo`
- `index.html#nube-saas`
- `index.html#agencia-norte`

Cada perfil cambia el destinatario de la portada, el mensaje, el servicio destacado y el orden de los casos.

## Tipografías de marca

Anantason Expand, Garet y Rocking Horse no están en Google Fonts. Si están instaladas en tu equipo se usan solas.
Para que se vean en cualquier equipo, copiá los archivos a `portfolio/fonts/` con estos nombres:
`AnantasonExpand.woff2`, `Garet.woff2`, `RockingHorse.woff2`.
Mientras tanto se usan equivalentes: Unbounded, Manrope y Shrikhand.
